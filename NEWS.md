# ivserial 1.0.1

* First R release. Same procedure, defaults and output as the Python package
  `ivserial` 1.0.1 (PyPI): `serial_test()`, `screen_series()`, the null limit,
  the serial Cramer coefficient, sample-size planning, `read_series()` and the
  graphical interface `ivserial_app()`.
